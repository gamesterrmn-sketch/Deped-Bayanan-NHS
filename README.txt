BAYANAN NATIONAL HIGH SCHOOL WEBSITE CONCEPT

Files:
- index.html
- styles.css
- script.js

How to use:
1. Keep all three files in the same folder.
2. Open index.html in a browser.
3. For publishing, upload the files to GitHub Pages, Netlify, Cloudflare Pages, or the school's approved hosting service.

Important before official publication:
- Replace the BNHS text seal with the approved school logo.
- Confirm all school descriptions, program names, contact details, and announcement dates.
- Add the official school email to the contact form or connect the form to an approved backend.
- Obtain permission for any student photos before publication.
- Review accessibility, privacy, and DepEd branding requirements.
